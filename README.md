# 余談商店 v20 — ほのぼの商店デザイン版

## このバージョンでできること

v19の機能と設定を維持したまま、管理画面・公開記事一覧・公開記事詳細のデザインを「余談商店」に統一しました。以前作成した猫のブランドロゴを軽量WebPで同梱しています。配色はクリーム、セージグリーン、木のブラウン。スマートフォンも対応しています。

- **作業台** `/`：商品検索・楽天ランキング・商店おすすめ・記事生成・D1保存/公開・Threads投稿を継続利用。上部メニューから各セクションへ移動できます。
- **商店の店先** `/shop`：読者向けの新しい入口。公開済み記事だけをカードで表示。作業台への誘導は表示しません。
- **公開記事一覧** `/articles`：既存URLを維持しながら、店先と同じデザインに刷新。
- **公開記事** `/articles/{記事ID}`：今までの投稿リンクを変えずに、読みやすい商店風レイアウトへ変更。
- **ブランドロゴ** `/yodan-logo.webp`：同梱された既存オリジナルの猫ロゴ。外部フォントや画像CDNは不要。

## 更新方法：旧Cloudflareアカウント専用

1. このZIPを解凍する。
2. **旧楽天アフィ用GitHubリポジトリ「楽天自動アフィリエイト」** に、中身をファイル/フォルダ単位で上書きアップロードする。GitHubのルートに `worker.js`・`wrangler.jsonc`・`public/` を置く。**ZIP自体をアップロードしない**。
3. GitHubのコミット後、Cloudflareの既存 Worker `rakuten-auto-affiliate` のデプロイ状態を確認する。
4. `https://rakuten-auto-affiliate.116kousei0428.workers.dev/api/health` に `"release":"v20"` が表示されたら、管理画面 `/` と読者向け `/shop` を確認する。GitHubやCloudflareの別アカウント `yodan-shoten` にはアップロードしない。

## 安全性と引継ぎ

- **CloudflareのWorker名、従来のD1バインディング `DB` とデータベースID `81926891-4dd8-4cc2-b966-e530d2912452`、Workers AI、Threads接続、APIエンドポイントは変更していません。**
- 既存のD1に保存した記事・Threads投稿・管理者キー・API Secretを削除/再作成しません。Secret本体はZIPには含まれません。ブラウザ側の任意保存キー名も従来どおりです。
- デザイン変更では商品画像のSNS転載権限は変わりません。v19と同様、Threadsに添付する画像は利用権利を確認してから使ってください。
- 「案件」スイッチは毎回OFFで、ON時だけ投稿文冒頭に【PR】を付ける従来動作を維持しました。広告表記は実際の取引条件・掲載媒体のルールに応じて判断してください。
- 公開する記事には従来どおりアフィリエイト広告の注記を表示します。

## 確認方法と制約

`npm run check` を実行すると、認証・楽天API処理・D1・記事公開・Threadsの既存テストと、今回追加した `/shop` のテストを実行します。
**本番デプロイ、実際の商品購入・Threads実投稿はこのZIP作成時点では未検証です。** ローカルの見た目と自動テストは確認しました。

公開記事一覧のカード画像は、現状ではイラスト風の絵文字で表示します（実在商品と誤認させないため）。記事本文中の既存の楽天リンクは維持しています。商品写真のSNS自動転載はしていません。
