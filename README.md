# 楽天アフィリエイト v19 — 楽天ランキング・商店おすすめピックアップ

## 更新方法

**既存v16/v17に上書きする更新版です。** ZIPを解凍して中身のファイル・フォルダを、楽天アフィリエイト用GitHubリポジトリのルートにアップロードしてください。**POSのGitHubリポジトリにはアップロードしないでください。** ZIPフォルダをそのまま１階層追加せず、`worker.js`・`wrangler.jsonc`がリポジトリ直下に置かれるようにします。

デプロイ後、`https://rakuten-auto-affiliate.116kousei0428.workers.dev/api/health` の `release: "v19"` で反映を確認できます。CloudflareとGitHubが連携されている前提です。

## v17から引き継ぐ改善

1. **月面ライト優先** — 商品名が月面ライト／ムーンライトの場合、一般の照明雑学ではなく「月の自転と公転」「月の裏側にも光が当たる」など、月に直接関係する雑学を使います。月に関する内容はNASAの一次資料を参照しています（https://science.nasa.gov/moon/facts/）。
2. **ジャンルの誤判定を抑制** — 商品名からのみ分類し、本文の一般的な説明・おすすめチェック項目には影響されません。照明・イヤホン・酒・コーヒー・紅茶など既存分を含む20テーマに対応。
3. **無関係な雑学の自動挿入を禁止** — マッチする雑学がない商品は明示エラー（422 / `NO_VERIFIED_TRIVIA`）で生成しません。AIがもっともらしい虚偽の雑学を補完する仕組みはありません。
4. **案件スイッチ（初期OFF）** — Threads投稿文の生成・再生成では通常PR表記なし。「案件」をONにした場合だけ冒頭「【PR】」を挿入します。見出し・区切り・末尾のPR注記は付きません。編集保存ではPRの有無を強制しません。
5. **別の雑学へ再生成** — 未投稿の下書きはボタン操作で同テーマの別候補へ変更できます。編集中の文章は上書きするため、必要ならコピーして保存してください。投稿済みには適用されません。

## 既存設定の維持

Cloudflare Worker名 `rakuten-auto-affiliate`、Workerのエントリポイント `./worker.js`、D1バインディングとデータベースID、Workers AIバインディング、楽天API、Threads API、保存記事、公開記事、既存のSecretは変更・削除しません。**Secretの値はZIPに含めていません**。管理者キーを保存する `localStorage` のキー名も変更していないため、既存の保存設定は維持されます。

既存v16/v17のThreads投稿下書きは自動変更されません。「別の雑学で再生成」で新しい形式に更新できます（投稿済みは変更不可）。現在のThreads投稿機能は管理者による承認後の手動投稿です。

## 検証と限界

`npm run check` でファイル構造・認証・D1・Threads・カテゴリ判定のローカルテストを実行できます。**本番のCloudflareデプロイやThreadsへの実投稿はこのZIPの作成時点では未実施です。** また、任意の商品を無制限に扱えるわけではありません。新しいジャンルの雑学は内容の検証後に追加が必要です。商品の個別仕様と投稿内容は送信前に確認してください。

## v18 新機能：人気商品・注目商品のピックアップ

- **楽天ランキング**：`①-2 人気・注目商品ピックアップ` → 「楽天の人気ランキングを見る」で楽天公式 **Ichiba Item Ranking API 2022-06-01** を利用し、実際の順位・商品名・価格・画像・ショップ名を表示します。楽天側の更新時刻が返る場合は併記します。**順位や商品情報を独自に生成しません。** 1回の取得は最大12件、Edgeキャッシュは15分でAPI呼び出しを抑制します。
- **商店おすすめ**：編集上の仮説として、月面ライト／プラネタリウム／真空断熱タンブラー／イヤホン／コーヒードリッパー／モバイルバッテリー／折りたたみ傘／ロボット掃除機の8テーマを表示します。各テーマをクリックすると**楽天商品検索APIから実在の候補商品を取得**します。「流行中」「売れている」とは断言しません。
- **AI記事へ接続**：ランキングからも編集候補からも、既存の「AI記事を作成」を直接利用できます。D1、Threads、管理者キー設定は従来どおりです。
- **API権限に関する注意**：既存の検索API権限だけではランキングAPIの実行権限がない場合があります。ランキングが403なら、楽天Web Serviceの管理画面でランキングAPIの利用権限を確認してください。検索・記事生成機能は引き続き使えます。
- **ランキング更新の限界**：実際の本番アクセスはデプロイ後に確認してください。リアルタイムランキングと呼ばず、楽天APIが返すランキング情報と更新時刻を表示しています。

参考：公式ランキングAPI仕様 https://webservice.rakuten.co.jp/documentation/ichiba-item-ranking

## v18.2：Threads「案件」切り替え

- Threadsセクションに「案件」スイッチを追加。画面を開くたびにOFFから始まり、ブラウザには保存しません。
- 新規生成・「別の雑学で再生成」時にスイッチのON/OFFを送信します。OFFなら普通の文章＋記事リンクのみ、ONなら冒頭に「【PR】」。生成結果には「ちょっとした雑学」「商品紹介」といった見出し・区切り線・末尾の注意書きは含めません。
- 保存済みのThreads下書きは勝手に書き換えません。すでに下書きがある記事でPRのON/OFFを変えたい場合は、スイッチを切り替えて「別の雑学で再生成」を押してください。投稿済みは変更しません。
- 機能は通常の楽天アフィリエイト案件を前提に設計。楽天公式は「事業者との情報等のやり取りがない」場合のPR表記を任意としますが、商品提供・広告主との企画などではPR表記が必要です。https://affiliate.rakuten.co.jp/guideline/stealth_marketing_regulation/
- AI記事そのものに付けているアフィリエイト注記は今回変更していません。**Threads投稿文**の生成形式だけを変更しています。

## v19：Threadsへの商品写真添付（利用権限を確認した場合のみ）

- Threadsの画像付き投稿はMeta公式の `POST /me/threads` に `media_type=IMAGE` + `image_url` + `text` を送り、その後 `/me/threads_publish` で公開。画像は**誰でもアクセスできるHTTPSの直接画像URL**が必要。
- 商品の検索APIから得た写真はプレビューとして記事に関連付け（D1の新規 `article_media` テーブル）、記事公開後にThreads画面に自動表示。既存の記事・旧データ・Threadsの認証情報はそのまま。
- **重要**：楽天アフィリエイト公式では、楽天アフィリエイトのリンク作成画面以外から取得した画像の無断ダウンロード・SNSへの転載を禁じています。楽天APIの画像URLをそのままThreadsに投稿してよいという許可は未確認なので、商品写真のThreads添付は初期OFF。利用許諾を確認した画像に限り、公開画像URLを設定して2つのチェック（権利・添付）をONにして投稿してください。無許諾の写真は添付しません。
- 画像URLが入っていない記事は、既存の文章投稿を継続。過去のThreads投稿・記事内容を変更しません。
- 実際のMeta画像投稿・権限・画像ホスティングはローカルでは確認できません。投稿前に実画像URLとMeta側の仕様を確認してください。
- 画像はThreads側のAPIがURLにアクセスできる必要があります。HTMLページのURLやログイン制限付きURLでは失敗します。

公式の注意事項: https://affiliate.rakuten.co.jp/know-how/susumeru/
Meta公式API例: https://www.postman.com/meta/threads/documentation/dht3nzz/threads-api
